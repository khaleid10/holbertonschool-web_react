# TypeScript

Holberton School TypeScript project covering tasks 0 through 10.

## Topics

- Basic TypeScript types
- Interfaces and classes
- Functions and type predicates
- String literal types
- Ambient declarations
- Namespaces and declaration merging
- Nominal typing

## Tasks

- `task_0`: Student interface and DOM table
- `task_1`: Teacher and Director interfaces, functions, and StudentClass
- `task_2`: Advanced employee types and string literal types
- `task_3`: Ambient declarations and CRUD operations
- `task_4`: Namespaces and declaration merging
- `task_5`: Brand convention and nominal typing

## Build

Run `npm install` and `npm run build` inside each task directory.
